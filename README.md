# CanSat-Cola-Zero
CanSat, a miniaturized satellite designed for educational and competitive purposes.
Our CanSat is built around an ESP32, equipped with multiple sensors, and uses LoRa communication for real-time data transmission.

To ensure data security, we implement encryption and decryption, combining lightweight cryptographic techniques such as AES-128 and XOR encryption to secure telemetry data during transmission.

Features
✅ ESP32-based flight computer
✅ Sensor suite (e.g., temperature, pressure, altitude, GPS)
✅ LoRa communication for telemetry
✅ Data encryption and decryption for secure transmission
✅ CRC/HMAC for data integrity

Technologies Used
- ESP32 (Microcontroller)
- LoRa (Long-Range Communication)
- AES-128, XOR Cipher (Encryption)
- C++ & Arduino Framework
